# Sportarr Runtipi App Store

The official [Runtipi](https://runtipi.io) app store for [Sportarr](https://sportarr.net), the sports PVR for Usenet and BitTorrent.

## Add this store to Runtipi

Runtipi v4.0.0 and above supports custom app stores.

1. In your Runtipi dashboard, open **Settings** and click **App Stores**
2. Click **Add App Store**
3. Paste this repository URL and give the store a name, for example `Sportarr`

```
https://github.com/Sportarr/runtipi-appstore
```

Sportarr then appears in your app store list, ready to install.
